# Contributing to Clever Forms

Thanks for helping improve Clever Forms.

## Good contributions

- bug fixes
- accessibility improvements
- Payload compatibility fixes
- tests
- translations
- documentation
- examples
- safe additions to core field types

Premium CleverForge products and hosted-service implementations are developed separately and are not part of this public repository.

## Development

```bash
npm install
npm run typecheck
npm test
```

Please keep changes focused and add tests for behavior changes.

## Pull requests

Explain what changed, why it changed, and how it was tested. Avoid unrelated formatting changes in the same pull request.
