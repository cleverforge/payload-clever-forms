# Security Policy

Clever Forms accepts untrusted public input and treats security as a core requirement.

## Reporting a vulnerability

Please do not publish exploitable security vulnerabilities in a public GitHub issue.

Until a dedicated security mailbox is published, open a GitHub issue containing only a high-level request for a private security contact. Do not include exploit details, credentials, personal data, or proof-of-concept payloads in the public issue.

## Scope

Security reports may include authentication or authorization bypasses, submission-data exposure, validation bypasses, injection flaws, cross-site scripting, unsafe file handling, dependency vulnerabilities with demonstrated impact, or other issues that could affect confidentiality, integrity, or availability.

## Supported versions

Before 1.0.0, only the latest release is expected to receive fixes.
